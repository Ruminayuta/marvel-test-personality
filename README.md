# HERO / WITHIN

スパイダーマン／デッドプールのどちら寄りかを12問で楽しむ、日本語・英語対応の非公式性格診断サイトです。

## 起動

Node.js 20以上で、プロジェクトフォルダから実行します。追加パッケージのインストールは不要です。

```powershell
npm run dev
```

http://localhost:4173 を開きます。停止はターミナルで Ctrl+C。HTMLの直接ダブルクリックでは、JavaScriptモジュールが動作しないためHTTPサーバーを使ってください。

## テスト

```powershell
npm test
```

採点の両端・中間・逆転項目、不正な回答、15,625パターンの割合合計、翻訳キーの整合、共有URLの回答除去、結果説明の項目選択を検証します。

## 構成

- `dist/`：そのまま静的ホスティングへ配置する公開ファイル。
- `dist/data.js`：質問ID、採点方向、採点と共有URLの純粋関数。
- `dist/i18n.js`：共通キーで管理する日英の質問・画面・結果文。
- `dist/app.js`：画面遷移、回答、言語、共有。回答はメモリー内のみで、再読み込みで破棄。保存するのは言語設定だけです。
- `scripts/serve.mjs`：ローカル確認用サーバー。一般公開用サーバーではありません。
- `tests/quiz.test.mjs`：Node.js標準テスト。

## 言語・共有

`?lang=ja` / `?lang=en` が最優先、次に保存済み言語、最後にブラウザーの優先言語を使用します。共有URLは言語指定以外のクエリとフラグメントを除去し、トップ画面を開きます。Web Share、Clipboard、選択コピー用テキストの順に対応します。言語変更で回答は失われません。

## 公開

`dist` フォルダの内容を静的ホスティングに配置してください。ビルド不要、サーバー関数・秘密鍵・データベース不要です。サブディレクトリ配置にも対応します。HTTPSで公開すると、対応ブラウザーの共有・クリップボード機能が利用できます。

この環境ではSitesの公開ツールおよび接続済みの公開先が提供されていないため、一般公開用URLは未発行です。ローカルURLは、このPC以外に共有する公開URLではありません。

Google Fontsを読み込みますが、読み込めない場合もシステムフォントで利用できます。画像、質問、診断機能はローカルのファイルで完結しています。

## 画像

`dist/assets/hero-duo.png` は組み込みImageGenで制作した独自デザインのイラストです。制作指示は `ASSET-PROMPT.txt` に保存しています。公式ロゴ、映画の写真、俳優の顔は使用していません。この制作方針や非公式表記は、法的な安全や権利者の許諾を保証するものではありません。

## 確認済み

- Node.js自動テスト6件合格。
- Microsoft Edgeで、12問の回答、未回答制御、戻る・回答変更、途中と結果での日英切り替え、50/50表示、共有のコピー代替、再診断、再読み込みを確認。
- ブラウザー言語からの初期選択、言語の保存、URL言語指定を確認。
- スマホ幅390pxで英語のトップ・質問・結果に横はみ出しがないことを確認。
- デスクトップ・スマホの画面キャプチャを目視確認。確認時にJavaScriptエラーなし。
- 端末のネイティブ共有シートによる実際の他アプリへの送信は未実施。
